### 2. New `opensearch-sql` connector (design only, no code yet)
- Spec (uncommitted at handover time): `docs/superpowers/specs/2026-10-02-opensearch-sql-connector-foundation-design.md`. Approved by the user as "sub-project 1: foundation + aggregation". Next step: write the implementation plan (superpowers:writing-plans), then execute it.
- Decisions: new module `plugin/trino-opensearch-sql`, depends on `trino-opensearch`; scans stay on scroll; global aggregates (incl. `stddev`/`variance`) via `POST /_plugins/_sql`; `GROUP BY` stays on DSL composite paging; `WHERE` rendered into SQL text; engine-fallback detection by result types; new `opensearch.sql.global-aggregation-engine` (`SQL`|`DSL`).
- Why: probes of a shared OpenSearch 2.19 cluster found (a) `GROUP BY` silently truncates at 1,000 groups, (b) empty `sum()` returns 0, (c) `BIGINT` aggregates lose precision, (d) the REST `filter` parameter is silently ignored and the engine can fall back to V1 with different result types. See the table in the spec.
- Later sub-projects: expression pushdown, join/subquery feasibility spike, hardening.
- Shared test cluster: ask Joongjin for the endpoint; pass it as env var `OS_SQL_URL` (and `OS_SQL_USER`/`OS_SQL_PASSWORD` if needed). Use read-only requests only. The old `sqlprobe.py` probe script is not in the repo (it hard-codes the endpoint).

## Environment lessons (old laptop)
- Maven could not compile `trino-main` when Windows commit memory was exhausted (close memory-heavy apps or raise the paging file); it worked afterwards with `./mvnw install -pl plugin/trino-opensearch -am -DskipTests -Dair.check.skip-all=true -Dskip.bun=true -nsu`.
- Airbase enforcer needs a Temurin or Oracle JDK; use one on the new laptop to avoid the skip flags.
- Set `git config core.autocrlf input` (or `false`) in the new clone so `airstyle:format` does not rewrite every file's line endings.
- Docker: Rancher Desktop with the dockerd (moby) engine, started before running the integration tests.
- Test command: `./mvnw -pl plugin/trino-opensearch test -Dtest='TestOpenSearchConfig,TestOpenSearchMetadata,TestOpenSearchQueryBuilder,TestAggregationModel,TestAggregationResponseReader,TestTopN' -Dair.check.skip-all=true -nsu`.
